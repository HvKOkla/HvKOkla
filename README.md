# Hi there, I'm Quentin 👋

**Founder of [Slytherin-RL](https://github.com/HvKOkla/Slytherin-RL)** — *A modular Reinforcement Learning framework for Edge AI.*

I'm an **AI & Tools Developer** passionate about building things from the ground up, optimizing for low-end devices, and designing programming languages.

### What I Do

- **AI Engineering** — Training agents with PPO and optimizing models for edge inference.
- **Tooling & Architecture** — Designing clean, modular systems (Engine/Game separation), interactive dashboards with Streamlit, and scripting custom developer tools.
- **Low-Level Math** — Implementing algorithms from scratch in NumPy to master the fundamentals.
- **Language Design & Scripting** — Explored language creation from first principles and currently focusing on embedded scripting with **Lua** (Defold, LÖVE).
- **Game & Engine Tech** — Prototyping and tooling with Defold, LÖVE, and C++.
